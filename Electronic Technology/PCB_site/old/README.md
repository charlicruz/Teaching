# Electronics Learning Hub

Static site ready for GitHub Pages.

## Publish

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. In GitHub, open **Settings > Pages**.
4. Set **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save and wait for the site URL.

## Edit

- Main page: `index.html`
- Styles: `assets/css/style.css`
- Images: `assets/img/`

## Notes

This version uses your uploaded images and an original layout inspired by the structure of your source pages.

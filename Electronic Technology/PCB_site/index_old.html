Resumen del proyecto

From prototyping to a real PCB

Del prototipado a una PCB real

Updated 2025.02.28 · Original project by Patrick R Cabanban
Actualizado 2025.02.28 · Proyecto original de Patrick R Cabanban

In this project you move beyond breadboards and perfboards and create a complete printed circuit board for the classic 555 blinker using KiCad 7. The objective is to capture the schematic, assign the correct footprints, lay out the PCB and generate manufacturing files.

En este proyecto darás el salto desde las breadboards y placas perforadas hacia una placa de circuito impreso completa del clásico 555 blinker usando KiCad 7. El objetivo es capturar el esquema, asignar las huellas correctas, diseñar la PCB y generar los ficheros de fabricación.

Printed Circuit Boards (PCB)

Placas de circuito impreso (PCB)

PCBs are used when circuits are ready for more compact, reliable and reproducible implementations. They connect components on a board designed with CAD tools and make complex circuits easier to build and mass produce.

Las PCB se utilizan cuando un circuito requiere una implementación más compacta, fiable y reproducible. Conectan componentes sobre una placa diseñada con herramientas CAD y permiten fabricar circuitos complejos con mayor facilidad.

PCB Design Overview

Visión general del diseño PCB

The workflow has two main stages: schematic capture and PCB layout. First you represent the circuit digitally, then you position components, route traces and prepare the board for fabrication.

El flujo de trabajo tiene dos etapas principales: captura del esquemático y diseño del layout PCB. Primero representas digitalmente el circuito y después colocas los componentes, enrutas pistas y preparas la placa para fabricar.

Instructions and checkpoints

Instrucciones y checkpoints

The project is divided into five checkpoints that take you from a new KiCad project to manufacturing outputs.

El proyecto se divide en cinco checkpoints que te llevan desde un proyecto nuevo en KiCad hasta los ficheros de fabricación.

Checkpoint 1

Create the project and capture the schematic

Crear el proyecto y capturar el esquemático

  1. Create a new KiCad project and open the schematic editor.
  2. Crea un nuevo proyecto de KiCad y abre el editor esquemático.
  3. Add power symbols, parts, values and footprint assignments.
  4. Añade símbolos de alimentación, componentes, valores y asignación de huellas.
  5. Wire the circuit, add net labels and no-connection flags.
  6. Cablea el circuito, añade etiquetas de red y marcas de no conexión.
Checkpoint 2

Annotate and validate the schematic

Anotar y validar el esquemático

  1. Run schematic annotation to replace placeholder references.
  2. Ejecuta la anotación del esquema para reemplazar referencias temporales.
  3. Run ERC and verify that only the expected power warning remains.
  4. Ejecuta el ERC y comprueba que solo queda la advertencia de alimentación esperada.
Checkpoint 3

Create the board and route the PCB

Crear la placa y enrutar la PCB

  1. Open PCB Editor and update the board from the schematic.
  2. Abre PCB Editor y actualiza la placa a partir del esquemático.
  3. Set track and via sizes, define board outline and place footprints.
  4. Configura tamaños de pistas y vías, define el contorno y coloca las huellas.
  5. Route tracks, add vias if needed, and create the ground fill.
  6. Enruta pistas, añade vías si hace falta y crea el plano de tierra.
Use 40 mil for power/ground and 30 mil for signal traces. Avoid 90° corners.
Usa 40 mil para alimentación/tierra y 30 mil para señal. Evita esquinas de 90°.
Checkpoint 4

Run design rule checks

Ejecutar las verificaciones de diseño

  1. Open DRC and run the checker.
  2. Abre el DRC y ejecuta la comprobación.
  3. Resolve all violations before generating outputs.
  4. Resuelve todas las violaciones antes de generar resultados.
Checkpoint 5

Generate manufacturing files

Generar ficheros de fabricación

  1. Plot the fabrication layers and create drill files.
  2. Genera los ficheros de capas de fabricación y los taladros.
  3. Review the generated files before submission.
  4. Revisa los ficheros generados antes de la entrega.
  5. Compress the project folder with the required naming format.
  6. Comprime la carpeta del proyecto con el formato de nombre solicitado.

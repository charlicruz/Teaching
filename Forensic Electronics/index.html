🎯 Objetivo del repositorio

  • Organizar y compartir contenidos propios sobre electrónica forense aplicada.
  • Publicar apuntes, ejercicios y casos prácticos.
  • Compilar enlaces a herramientas forenses y recursos didácticos.
  • Documentar estudios de caso en procesamiento de señales, instrumentación y recuperación de evidencias.

🔍 Forensic Electronics University of Alcalá (UAH)

Welcome to the repository of materials for the Forensic Electronics course, taught in the Master’s Degree in Forensic Engineering at the University of Alcalá (UAH).

📚 Official course page

Open official course page (UAH)

Note: the official page is available in Spanish.

🎯 Repository goals

  • Organize and share original content on applied forensic electronics.
  • Publish notes, exercises, and practical case studies.
  • Compile links to forensic tools and learning resources.
  • Document real-world experiences in signal processing, instrumentation, and evidence recovery.

🧰 Featured tools

Hands-on forensic software resources:

🗄️ Autopsy – Forensic analysis 🌐 Wireshark – Network traffic analysis

📂 Repository structure

/case_studies/        # Real or simulated forensic cases
/exercises/           # Instrumentation and analysis exercises
/tools/               # Forensic tools and scripts
/videos/              # Explanatory videos
/docs/                # Guides and reference documents

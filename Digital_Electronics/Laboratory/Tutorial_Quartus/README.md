# Quartus Tutorial: Combinational System Design

📺 **Video Tutorial:** [Watch on Zenodo](https://zenodo.org/records/15051349)

This repository contains support material for the video tutorial **"Combinational System Design with Quartus"**, part of the **Digital Electronics** course at the **University of Alcalá**.  
It is aimed at students and professionals learning to use **Quartus** for digital circuit design.

## 🎯 Objective

The goal of this tutorial is to demonstrate how to use **Intel Quartus** to create and simulate a basic **combinational digital system** composed of a **multiplexer and an adder**. Students are guided step-by-step through the process of:

- Creating a new project in Quartus
- Designing digital components
- Simulating circuit behavior
- Implementing logic in a **CPLD development board**

By completing this practice, learners acquire key skills for working with digital systems and development tools.

## 🧠 Intended Audience

- Undergraduate students in:
  - Telecommunication Technologies
  - Communication Electronics
  - Telecommunication Systems Engineering
  - Telematics Engineering
- Anyone interested in **digital system design** and learning how to use **Quartus** and **CPLD boards**

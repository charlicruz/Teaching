# Electrónica Digital – Universidad de Alcalá

Bienvenido/a a este repositorio general de **materiales, ejercicios y recursos multimedia** relacionados con la asignatura **Electrónica Digital**, impartida en varios grados de ingeniería en la **Universidad de Alcalá** (UAH).

📚 **Página oficial de la asignatura:**  
[https://www.uah.es/es/estudios/estudios-oficiales/grados/asignatura/Electronica-Digital-350007/](https://www.uah.es/es/estudios/estudios-oficiales/grados/asignatura/Electronica-Digital-350007/)

---

## 🎯 Objetivo de este repositorio

Este espacio tiene como finalidad:

- Organizar y compartir **contenidos propios** creados para la asignatura.
- Recopilar **ejercicios prácticos**, **proyectos de diseño**, y **recursos didácticos**.
- Registrar los **videos explicativos** desarrollados para apoyar el aprendizaje.
- Enlazar a los **repositorios públicos** con ejercicios, simulaciones y documentación.

Este repositorio se irá actualizando progresivamente con nuevo material.

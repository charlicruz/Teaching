# Electronics Design with VHDL: Selected Exercises

This repository contains a curated collection of VHDL exercises from  
**"Electronics Design with VHDL: Selected Exercises"** by **Dr. Carlos Cruz de la Torre**, University of Alcalá.  
The material is designed to support students in mastering the syntax, design methodologies, and simulation techniques of VHDL (VHSIC Hardware Description Language).

## 📘 Contents

The exercises are organized around the following key topics:

- **Identifiers and Literals**  
  Practice verifying valid VHDL identifiers and understanding literal types and type conversions.

- **Registers and Operators**  
  Tasks for detecting declaration/assignment errors and evaluating logical/arithmetic operations.

- **Basic Unit Design**  
  Design exercises for:
  - Binary adders
  - Multiplexers
  - Comparators  
  Using **structural**, **dataflow**, and **algorithmic** styles.

- **Signal and Variable Behavior**  
  Scenarios analyzing differences between signal and variable behavior inside VHDL processes.

- **Testbenches**  
  Implementation of testbenches to validate VHDL modules through simulation.

- **File Handling in VHDL**  
  Exercises on reading/writing external files for:
  - Test vector generation
  - Simulation result storage

- **Finite State Machines**  
  Design and simulation of **Moore** and **Mealy** state machines.

## 🎓 Target Audience

These exercises are ideal for:
- Undergraduate and graduate students in **Telecommunications** or **Electronic Engineering**
- Learners seeking hands-on practice with VHDL-based digital design
- Instructors looking for structured material to complement VHDL courses
